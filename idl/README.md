# Program IDLs

Generated by the Anchor CLI from the program sources with the `idl-build` feature; committed so that every client
is rendered from the same artefact that the audit reviewed.

```
cd programs
anchor idl build -p brink_index    -o idl/brink_index.json
anchor idl build -p brink_timelock -o idl/brink_timelock.json
anchor idl build -p swap_amm       -o idl/swap_amm.json
```

Toolchain pins live in `Anchor.toml` (`anchor_version` equals the `anchor-lang` crate version in
`Cargo.toml`; `solana_version` equals the installed Agave CLI). Regenerate after any change to an instruction,
account, event or error, then `npm run codama -w packages/chain` to re-render the TypeScript clients under
`packages/chain/src/generated/`. The IDL `address` fields are the devnet program ids.
